## ⚡ Pourquoi TrimOS ?

Les téléviseurs connectés d'aujourd'hui sont envahis par des publicités vidéo plein écran intempestives, des aperçus en lecture automatique, des carrousels sponsorisés et des processus de télémétrie agressifs qui saturent jusqu'à 80 % de la mémoire vive de votre TV.

**TrimOS** remplace entièrement les applications et surcouches constructeurs (Xiaomi PatchWall, recommandations Google TV, bannières sponsorisées Fire TV, etc.) par un environnement fluide, haute performance et débarrassé de toute distraction, inspiré de l'élégance d'Apple TV :

| Fonctionnalité | Smart TV d'Origine | TrimOS |
| :--- | :---: | :---: |
| **Publicités et Vidéos Automatiques** | ❌ Omniprésentes et intrusives | 🟢 **100 % sans publicité** |
| **Consommation de Mémoire RAM** | ❌ 600 Mo – 1,2 Go | 🟢 **~22 Mo (Ultra-léger)** |
| **Fluidité et Navigation** | ❌ Ralentissements fréquents | 🟢 **Interface fluide 60 ips** |
| **YouTube sans Publicité** | ❌ Coupures publicitaires régulières | 🟢 **SmartTube avec SponsorBlock** |
| **Saisie des Mots de Passe** | ❌ Fastidieuse à la télécommande | 🟢 **Scannez le QR et tapez sur mobile** |
| **Souris Virtuelle / Pavé Tactile** | ❌ Inexistante | 🟢 **Trackpad complet avec glisser-déposer** |
| **Personnalisation des Thèmes** | ❌ 1 habillage figé constructeur | 🟢 **32 Thèmes intégrés** |
| **Recherche Streaming Universelle** | ❌ Restreinte aux services partenaires | 🟢 **Recherche unifiée multi-plateformes** |
| **Réattribution des Boutons** | ❌ Touches partenaires verrouillées | 🟢 **Télécommande 100 % personnalisable** |
| **Accès Root Requis** | ⚠️ Risqué et complexe | 🟢 **Aucun Root requis (ADB sécurisé)** |

## 🚀 Démarrage Rapide

### Prérequis
1. **Activer les Options pour les développeurs et le Débogage ADB sur votre TV** :
   - Accédez aux **Paramètres** de la TV → **Préférences relatives à l'appareil** → **À propos**.
   - Appuyez 7 fois consécutives sur **Build / Numéro de build** jusqu'au message *"Vous êtes désormais développeur !"*.
   - Revenez dans les **Options pour les développeurs** et cochez **Débogage USB** et **Débogage réseau / ADB**.
2. Assurez-vous que votre ordinateur et le téléviseur sont connectés au même réseau Wi-Fi.

---

### Installation Automatique en 1 Clic (Recommandée)

Clonez le dépôt et lancez l'installateur universel :

```bash
git clone https://github.com/chiragchanchal/TrimOS.git
cd TrimOS
```

#### Sur Windows :
```powershell
python trimos.py install --ip <IP_DE_VOTRE_TV>
# ou double-cliquez simplement sur trimos.bat
```

#### Sur macOS / Linux :
```bash
python3 trimos.py install --ip <IP_DE_VOTRE_TV>
```

*L'installateur détectera automatiquement le constructeur de votre téléviseur, installera l'APK TrimOS, activera la protection permanente de la touche Accueil, désactivera en toute sécurité les flux publicitaires et installera l'édition adéquate de SmartTube sans publicité selon l'architecture du processeur.*

---

### Installation Manuelle (Sans Python)

Si vous disposez déjà d'`adb` sur votre ordinateur :

```bash
# 1. Se connecter au téléviseur
adb connect <IP_DE_VOTRE_TV>:5555

# 2. Installer TrimOS
adb install -r -g release/TrimOS-v1.0.apk

# 3. Activer le service d'accessibilité pour la touche Accueil et le pavé tactile
adb shell settings put secure enabled_accessibility_services com.gathin.tvhome/.HomeKeyService
adb shell settings put secure accessibility_enabled 1

# 4. (Facultatif) Installer SmartTube
# Pour téléviseurs 32 bits (Mi TV 4A/4C, FireStick, etc.) :
adb install -r release/SmartTube-v32.71-armeabi-v7a.apk
# Pour téléviseurs 64 bits (Shield TV, Google TV récents) :
adb install -r release/SmartTube-v32.71-arm64-v8a.apk

# 5. Démarrer TrimOS
adb shell am start -n com.gathin.tvhome/.MainActivity
```

## 📱 Connexion Mobile & Pavé Tactile Virtuel

Chaque téléviseur TrimOS dispose d'un contrôleur web local accessible directement sur votre réseau domestique sans passer par le cloud :

1. Cliquez sur l'**icône QR** dans la barre supérieure du téléviseur (ou ouvrez `http://<ip-tv>:8080` sur votre mobile).
2. **Pavé Tactile Virtuel** :
   - **Glisser le doigt** : Déplace le pointeur avec précision sur l'écran.
   - **Appuyer** : Clic.
   - **Mode Glisser** : Activez **Drag Mode: ON** pour déplacer des éléments.
   - **Boutons de Défilement** : Navigation rapide vers le haut ou le bas.
3. **Connexion Mobile** :
   - Saisissez vos mots de passe longs ou collez des URL depuis votre téléphone et touchez **"Send to TV Keyboard / Clipboard"**.
4. **Sélecteur de Thème Instantané** :
   - Changez le design de votre TV directement depuis le menu déroulant sur votre téléphone.

## 🛡️ Sécurité & Restauration en 1 Clic

TrimOS est **100 % non destructif** :
- La désactivation des logiciels indésirables s'effectue via `pm uninstall -k --user 0 <paquet>`, ce qui ne supprime les applications que pour la session active tout en laissant le système d'origine intact dans la mémoire morte.
- Aucun fichier système vital n'est effacé et aucun accès Root n'est nécessaire.

Pour revenir au lanceur d'origine à tout moment :

```bash
python trimos.py restore --ip <IP_DE_VOTRE_TV>
```

Cette commande réactivera immédiatement votre lanceur d'origine (PatchWall, Google TV, etc.).

## 🛠️ Commandes CLI et Utilitaires

L'utilitaire `trimos.py` simplifie la maintenance et le contrôle de votre TV :

```bash
# Vérifier l'état de la connexion, l'activité en cours et l'utilisation RAM
python trimos.py status --ip 192.168.1.9

# Déclencher un nettoyage de la mémoire vive à distance
python trimos.py clean --ip 192.168.1.9

# Changer de thème à distance
python trimos.py theme --theme-name aurora --ip 192.168.1.9

# Capturer une capture d'écran de la TV vers votre PC
python trimos.py screenshot --ip 192.168.1.9

# Ouvrir la télécommande web sur le navigateur de votre PC
python trimos.py remote --ip 192.168.1.9
```
