## ⚡ Warum TrimOS?

Heutige Smart-TVs sind geplagt von aufdringlicher Vollbild-Videowerbung, Autoplay-Trailern, gesponserten Karussells und aggressiven Telemetriediensten, die bis zu 80 % des knappen Arbeitsspeichers Ihres Fernsehers belegen.

**TrimOS** ersetzt die vorinstallierte Hersteller-Bloatware (Xiaomi PatchWall, Google TV Empfehlungen, Fire TV Werbebanner usw.) vollständig durch eine saubere, hochperformante und ablenkungsfreie Umgebung im Apple TV-Design:

| Funktion | Werkseitiger Smart TV | TrimOS |
| :--- | :---: | :---: |
| **Werbung & Autoplay-Videos** | ❌ Ständig überall sichtbar | 🟢 **100 % werbefrei** |
| **RAM-Verbrauch** | ❌ 600 MB – 1,2 GB | 🟢 **~22 MB (extrem leichtgewichtig)** |
| **Start- & Navigationsverzögerung** | ❌ Ruckelig und zäh | 🟢 **Flüssige 60-fps-Bedienung** |
| **Werbefreies YouTube** | ❌ Ständige 30-Sekunden-Clips | 🟢 **SmartTube mit SponsorBlock** |
| **Passworteingabe** | ❌ Mühsam per D-Pad der Fernbedienung | 🟢 **QR-Code scannen & am Smartphone tippen** |
| **Virtuelle Maus / Touchpad** | ❌ Nicht vorhanden | 🟢 **Volles Trackpad mit Drag & Drop** |
| **Theme-Anpassung** | ❌ 1 festgelegtes Hersteller-Design | 🟢 **32 integrierte Themes** |
| **Universelle Streaming-Suche** | ❌ Einseitige Herstellersuche | 🟢 **Einheitliche app-übergreifende Suche** |
| **Tastenbelegung ändern** | ❌ Fest verdrahtete Werbetasten | 🟢 **Frei belegbare Fernbedienung** |
| **Root erforderlich** | ⚠️ Riskant und komplex | 🟢 **Kein Root nötig (sicheres ADB)** |

## 🚀 Schnellstart

### Voraussetzungen
1. **Entwickleroptionen & ADB-Debugging am Fernseher aktivieren**:
   - Gehen Sie zu den TV-**Einstellungen** → **Geräteeinstellungen** → **Über das Gerät**.
   - Tippen Sie 7-mal auf **Build**, bis die Meldung *"Sie sind jetzt Entwickler!"* erscheint.
   - Wechseln Sie zurück in die **Entwickleroptionen** und aktivieren Sie **USB-Debugging** sowie **Netzwerk- / ADB-Debugging**.
2. Stellen Sie sicher, dass Computer und TV mit demselben WLAN-Netzwerk verbunden sind.

---

### Automatisierte 1-Klick-Installation (Empfohlen)

Klonen Sie das Repository und führen Sie das universelle Installationsskript aus:

```bash
git clone https://github.com/chiragchanchal/TrimOS.git
cd TrimOS
```

#### Unter Windows:
```powershell
python trimos.py install --ip <IHRE_TV_IP>
# oder einfach trimos.bat per Doppelklick starten
```

#### Unter macOS / Linux:
```bash
python3 trimos.py install --ip <IHRE_TV_IP>
```

*Das Skript erkennt automatisch den Hersteller Ihres Fernsehers, installiert das TrimOS-APK, aktiviert den permanenten Home-Tastenschutz, deaktiviert nervige Werbedienste risikofrei und installiert das passende werbefreie SmartTube für Ihre Prozessorarchitektur.*

---

### Manuelle Installation (ohne Python)

Falls Sie `adb` bereits auf Ihrem Computer eingerichtet haben:

```bash
# 1. Verbindung zum Fernseher herstellen
adb connect <IHRE_TV_IP>:5555

# 2. TrimOS installieren
adb install -r -g release/TrimOS-v1.0.apk

# 3. Barrierefreiheitsdienst für die Home-Taste & Touchpad aktivieren
adb shell settings put secure enabled_accessibility_services com.gathin.tvhome/.HomeKeyService
adb shell settings put secure accessibility_enabled 1

# 4. (Optional) SmartTube installieren
# Für 32-Bit-Geräte (Mi TV 4A/4C, Fire TV Stick etc.):
adb install -r release/SmartTube-v32.71-armeabi-v7a.apk
# Für 64-Bit-Geräte (Nvidia Shield TV, moderne Google TVs):
adb install -r release/SmartTube-v32.71-arm64-v8a.apk

# 5. TrimOS starten
adb shell am start -n com.gathin.tvhome/.MainActivity
```

TrimOS enthält maßgeschneiderte Herstellerprofile, die auf die systemspezifischen Pakete der einzelnen Marken abgestimmt sind:

| Marke / Plattform | Getestete Geräte | Was TrimOS bereinigt & optimiert |

| **Android TV Stock** | Sony Bravia, TCL, Hisense, Philips, Sharp, Skyworth | Ersetzt den trägen Leanback-Launcher. Bild- und Tonprofile bleiben voll funktionsfähig. |
| **Amazon Fire TV** | Fire TV Stick 4K / Max, Fire TV Cube, Omni Series | Umgeht die Fire OS Werbeübersicht und bindet die Home-Taste direkt an TrimOS an. |
| **OnePlus TV** | OnePlus TV Q1, U1S, Y1S | Entfernt OxygenPlay und herstellereigene Empfehlungsdienste. |
| **Generische TV-Boxen** | Nvidia Shield TV, Mecool, Dynalink, Formuler, X96 | Reines 60-fps-Erlebnis bei minimalem Speicherbedarf. |

## 📱 Mobiler Login & Touchpad-Fernbedienung

Jeder Fernseher mit TrimOS verfügt über eine lokale Weboberfläche ohne Cloud-Zwang in Ihrem Heimnetzwerk:

1. Drücken Sie auf das **QR-Symbol** in der oberen Leiste des Fernsehers (oder rufen Sie `http://<tv-ip>:8080` im Handy-Browser auf).
2. **Virtuelles Touchpad**:
   - **Finger bewegen**: Sanfte Mauszeiger-Steuerung auf dem TV.
   - **Tippen**: Klicken.
   - **Drag-Modus**: Aktivieren Sie **Drag Mode: ON** für Ziehen-und-Ablegen.
   - **Scroll-Tasten**: Komfortables Auf- und Abwärtsblättern.
3. **Mobiler Login**:
   - Tippen Sie Passwörter bequem am Smartphone ein und wählen Sie **"Send to TV Keyboard / Clipboard"**.
4. **Theme-Schnellwechsler**:
   - Wählen Sie Themes direkt über das Dropdown-Menü auf dem Smartphone aus.

## 🛡️ Sicherheit & 1-Klick-Wiederherstellung

TrimOS arbeitet **vollständig zerstörungsfrei**:
- Die Bloatware wird mit `pm uninstall -k --user 0 <paket>` lediglich für Benutzer 0 deaktiviert, bleibt im ROM erhalten und lässt sich jederzeit wieder reaktivieren.
- Es werden keine Systemdateien gelöscht und kein Root-Zugriff vorausgesetzt.

So stellen Sie den ursprünglichen Werkszustand Ihres Launchers wieder her:

```bash
python trimos.py restore --ip <IHRE_TV_IP>
```

Dadurch wird der werkseitige Launcher (PatchWall, Google TV usw.) sofort wieder aktiviert.

## 🛠️ CLI-Befehle & Werkzeuge

Das mitgelieferte Tool `trimos.py` dient als All-in-One-Werkzeug zur TV-Verwaltung:

```bash
# Verbindungsstatus, aktive App & RAM-Auslastung prüfen
python trimos.py status --ip 192.168.1.9

# RAM-Bereinigung aus der Ferne auslösen
python trimos.py clean --ip 192.168.1.9

# Theme remote wechseln
python trimos.py theme --theme-name aurora --ip 192.168.1.9

# Bildschirmfoto vom TV auf den PC übertragen
python trimos.py screenshot --ip 192.168.1.9

# Web-Fernbedienung im Browser öffnen
python trimos.py remote --ip 192.168.1.9
```
