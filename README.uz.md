## ⚡ Nega TrimOS?

Zamonaviy aqlli televizorlar toʻliq ekranli video reklamalar, avtomatik boshlanadigan lavhalar, homiylik karusellari va televizoringizning cheklangan tezkor xotirasining (RAM) 80% gacha qismini band qiladigan telemetriya xizmatlari bilan toʻlib ketgan.

**TrimOS** ishlab chiqaruvchining ogʻir dasturlarini (Xiaomi PatchWall, Google TV tavsiyalari, Fire TV reklama panellari va boshqalar) Apple TV uslubidagi toza, tezkor va chalgʻitmaydigan muhitga toʻliq almashtiradi:

| Xususiyat | Zavod Smart TV | TrimOS |
| :--- | :---: | :---: |
| **Reklamalar va Avto-videolar** | ❌ Hamma joyda doimiy mavjud | 🟢 **100% Reklamasiz** |
| **RAM Xotira Sarfi** | ❌ 600 MB – 1.2 GB | 🟢 **~22 MB (Oʻta yengil)** |
| **Ishga tushish va Menyu tezligi** | ❌ Qotuvchi va sekin | 🟢 **Bir tekis 60 fps silliq interfeys** |
| **Reklamasiz YouTube** | ❌ 30 soniyalik toʻxtovsiz reklamalar | 🟢 **SponsorBlock-li SmartTube** |
| **Parollarni Terish** | ❌ Pult yordamida qiyin va uzoq | 🟢 **QR kodni skanerlab telefondan yozish** |
| **Virtual Sichqoncha / Touchpad** | ❌ Mavjud emas | 🟢 **Drag & Drop qobiliyatli toʻliq sensor** |
| **Mavzularni Sozlash** | ❌ 1 xil qotib qolgan zavod koʻrinishi | 🟢 **32 ta Oʻrnatilgan Mavzu** |
| **Umumiy Qidiruv Tizimi** | ❌ Faqat reklama beruvchilar | 🟢 **Barcha ilovalar boʻylab umumiy qidiruv** |
| **Tugmalarni Qayta Biriktirish** | ❌ Qulflangan homiy tugmalari | 🟢 **Toʻliq sozlanuvchi pult** |
| **Root Kerakmi?** | ⚠️ Xavfli va murakkab | 🟢 **Root kerak emas (Xavfsiz ADB)** |

## 🚀 Tez Boshlash

### Talablar
1. **Televizorda Ishlab Chiquvchi Sozlamalari va ADB Debugging-ni Yoqing**:
   - TV **Sozlamalar** → **Qurilma sozlamalari** → **Haqida** boʻlimiga kiring.
   - *"Siz endi ishlab chiquvchisiz!"* yozuvi chiqquncha **Tizim versiyasi / Build** ustiga 7 marta ketma-ket bosing.
   - **Ishlab chiquvchi sozlamalari** menyusiga qaytib, **USB orqali nosozliklarni tuzatish (USB Debugging)** va **Tarmoq / ADB orqali tuzatish** parametrlarini yoqing.
2. Kompyuter va televizor bitta Wi-Fi tarmogʻiga ulanganiga ishonch hosil qiling.

---

### Avtomatlashtirilgan 1-Bosishda Oʻrnatish (Tavsiya etiladi)

Loyihani yuklab oling va universal oʻrnatuvchini ishga tushiring:

```bash
git clone https://github.com/chiragchanchal/TrimOS.git
cd TrimOS
```

#### Windows tizimida:
```powershell
python trimos.py install --ip <TELEVIZOR_IP_MANZILI>
# yoki shunchaki trimos.bat faylini ikki marta bosing
```

#### macOS / Linux tizimida:
```bash
python3 trimos.py install --ip <TELEVIZOR_IP_MANZILI>
```

*Dastur televizoringiz brendini avtomatik aniqlaydi, TrimOS dasturini oʻrnatadi, Bosh ekran (Home) tugmasini doimiy qulflaydi, keraksiz reklamalarni zararsiz oʻchiradi va protsessoringizga mos reklamasiz SmartTube dasturini joylaydi.*

---

### Qoʻlda Oʻrnatish (Python talab qilinmaydi)

Agar kompyuteringizda `adb` oʻrnatilgan boʻlsa:

```bash
# 1. Televizorga ulanish
adb connect <TELEVIZOR_IP_MANZILI>:5555

# 2. TrimOS-ni oʻrnatish
adb install -r -g release/TrimOS-v1.0.apk

# 3. Home tugmasi va sensorli pult xizmatini yoqish
adb shell settings put secure enabled_accessibility_services com.gathin.tvhome/.HomeKeyService
adb shell settings put secure accessibility_enabled 1

# 4. (Ixtiyoriy) SmartTube-ni oʻrnatish
# 32-bitli televizorlar uchun (Mi TV 4A/4C, FireStick va h.k.):
adb install -r release/SmartTube-v32.71-armeabi-v7a.apk
# 64-bitli televizorlar uchun (Shield TV, yangi Google TV-lar):
adb install -r release/SmartTube-v32.71-arm64-v8a.apk

# 5. TrimOS-ni ishga tushirish
adb shell am start -n com.gathin.tvhome/.MainActivity
```

## 📱 Mobil Kirish va Sensorli Pult

TrimOS oʻrnatilgan har bir televizor mahalliy Wi-Fi tarmogʻingizda bulutga bogʻlanmagan yengil veb-boshqaruvga ega:

1. Televizorning yuqori panelidagi **QR belgisi** ustiga bosing (yoki telefon brauzerida `http://<tv-ip>:8080` manzilini oching).
2. **Virtual Sensor (Touchpad)**:
   - **Barmoqni surish**: Ekranda kursor boshqaruvi.
   - **Tegish**: Tanlash va bosish.
   - **Surish rejimi**: Elementlarni surish uchun **Drag Mode: ON** rejimini yoqing.
   - **Aylantirish tugmalari**: Menyu boʻylab yuqoriga va pastga tez harakatlanish.
3. **Mobil Kirish**:
   - Uzun parollarni telefonda yozing va **"Send to TV Keyboard / Clipboard"** tugmasi orqali televizorga yuboring.
4. **Mavzuni Tezda Oʻzgartirish**:
   - Televizor mavzusini toʻgʻridan-toʻgʻri telefoningizdagi roʻyxatdan oʻzgartiring.

## 🛡️ Xavfsizlik va 1-Bosishda Tiklash

TrimOS **100% xavfsiz va qayta tiklanuvchidir**:
- Keraksiz ilovalarni oʻchirish `pm uninstall -k --user 0 <paket>` orqali amalga oshiriladi, bu esa dasturlarni faqat faol foydalanuvchi maydonidan oʻchiradi, zavod tizim fayllariga daxl qilmaydi.
- Hech qanday tizim fayli oʻchirilmaydi va Root huquqlari kerak emas.

Istalgan vaqtda zavod boshqaruviga qaytish uchun:

```bash
python trimos.py restore --ip <TELEVIZOR_IP_MANZILI>
```

Ushbu buyruq asl zavod boshqaruvini (PatchWall, Google TV va h.k.) darhol qayta yoqadi.

## 🛠️ CLI Buyruqlari va Vositalar

Qulay `trimos.py` dasturi televizorni boshqarish uchun keng imkoniyatlar beradi:

```bash
# Ulanish holati, faol ilova va RAM hajmini tekshirish
python trimos.py status --ip 192.168.1.9

# Masofadan RAM tozalashni ishga tushirish
python trimos.py clean --ip 192.168.1.9

# Masofadan mavzuni oʻzgartirish
python trimos.py theme --theme-name aurora --ip 192.168.1.9

# Televizordan kompyuterga skrinshot saqlash
python trimos.py screenshot --ip 192.168.1.9

# Mobil pultni kompyuter brauzerida ochish
python trimos.py remote --ip 192.168.1.9
```
